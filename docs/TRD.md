# Technical Requirements Document

## Architecture
- Static generation where possible.
- Next.js 15 App Router.
- No backend (JSON mock data and placeholders).

## Performance Targets
- AVIF/WebP, Lazy loading, Font optimization, Dynamic imports.
- **LCP:** under 2s
- **CLS:** under 0.05
- **TBT:** under 100ms
