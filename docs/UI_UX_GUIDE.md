# UI/UX Guide

## Brand Direction
- **Think:** Equinox, Nike, Porsche, Apple
- **Words:** Premium, Powerful, Elegant, Clean

## Colors
| Name | Hex |
| --- | --- |
| Black | `#050505` |
| Charcoal | `#121212` |
| Gold | `#D4AF37` |
| White | `#F8F8F8` |

## Typography
| Usage | Font |
| --- | --- |
| Hero/Headings | Bebas Neue |
| Body | Manrope |

## Design Rules
- Large spacing
- Big typography
- Soft gradients
- Glassmorphism
- Gold highlights

## Animation System
- **Hero:** Slow parallax
- **Cards:** Lift + shadow
- **Buttons:** Gold glow
- **Images:** Zoom on hover
- **Counters:** Spring animation
- **Sections:** Fade + stagger
- Duration: 200–600ms (No excessive bouncing).
